# Embedded C Bit Manipulation

My first practical Embedded C project.

This project demonstrates fundamental bit-level operations used in
embedded systems and microcontroller programming.

## Concepts

- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bit shifting
- Setting individual bits
- Clearing individual bits
- Toggling individual bits
- Reading individual bits
- Binary representation

## Operations

```c
SET_BIT(reg, bit)
CLEAR_BIT(reg, bit)
TOGGLE_BIT(reg, bit)
